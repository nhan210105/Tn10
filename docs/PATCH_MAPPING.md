# TnCheat patch mapping

12 UI slots are mapped by game and display name. Apply/Restore operates only on files the app is permitted to manage inside its sandbox/workspace.

FFTH: Aim Drag, Aim Magic, Aim Neck, Aim Chest, Aim Body, Aim R8.
FFMAX: Aim Drag, Aim Magic, Aim Neck, Aim Chest, Aim Body, Aim R8.

Missing package files are never silently replaced by another package.
